Why Time.deltaTime?

Your game runs fine on your machine, then a friend with a faster PC says everything moves at double speed. Here's why, and the one-line fix every Unity dev learns the hard way.

What you're watching

Both cubes were tuned to feel right at 60 FPS. The red one moves a fixed amount every frame. The green one multiplies by deltaTime, the seconds since the last frame.

Drop the FPS to 15. Red crawls. Crank it to 240. Red rockets ahead. Green stays the same speed at every setting. That's the bug Time.deltaTime fixes.

Show me the code 
void Update() {
  // Red cube — frame-rate dependent (BUG)
  redCube.position += new Vector3(speed, 0, 0);

  // Green cube — frame-rate independent
  greenCube.position += new Vector3(speed * Time.deltaTime, 0, 0);
}
