What each knob does

  • Mass — heavier balls shrug off kicks. Same impulse, less velocity (F = ma).
  • Drag — air resistance. Bleeds velocity over time. Try 2.0 and watch the ball float down.
  • Gravity scale — multiplier on the world's -9.81 m/s². Negative values send the ball up.
  • Bounciness — fraction of velocity preserved on hit. 0 = thud. 1 = forever.
Show me the Unity equivalent 
var rb = GetComponent<Rigidbody>();
rb.mass         = 1.0f;   // kilograms
rb.drag         = 0.0f;   // linear damping
rb.useGravity   = true;
Physics.gravity = new Vector3(0, -9.81f, 0);

// Bounciness lives on a PhysicMaterial
collider.material.bounciness    = 0.6f;
collider.material.bounceCombine = PhysicMaterialCombine.Maximum;

// Kick = impulse force divided by mass
rb.AddForce(Vector3.right * 10f, ForceMode.Impulse);
