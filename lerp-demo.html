Lerp, explained

Linear motion is the dead giveaway of an unfinished game. Smooth motion is one line of code, but only if you feed it the right curve. Try seven.

A (0,0,0) pos.x = 0.00 B (10,0,0)
t0.00

What's actually happening

Vector3.Lerp(A, B, t) is linear interpolation. At t=0 you're at A. At t=1 you're at B. At t=0.5 you're exactly halfway. That's it. No magic.

Easing isn't a Lerp feature. It's a curve you run t through before Lerp sees it. Lerp still draws a straight line, but you've bent how fast you travel along it.

Linear feels robotic. EaseOut feels natural for arrivals (slowing into a target). SmoothStep is the everyday workhorse, gentle on both ends.

Show me the Unity equivalent 
void Update() {
  // Raw progress: 0 → 1 over `duration` seconds
  float t = (Time.time - startTime) / duration;
  t = Mathf.Clamp01(t);

  // Bend t through an easing curve (this is the secret sauce)
  t = Mathf.SmoothStep(0f, 1f, t);

  // Lerp itself is always linear — easing lives in t
  transform.position = Vector3.Lerp(pointA, pointB, t);
}

// Roll your own:
float EaseOutQuad(float t) => t * (2f - t);
float EaseInQuad(float t)  => t * t;
